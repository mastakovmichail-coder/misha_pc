FSOCIETY PC CONTROL — ИНСТРУКЦИЯ

========================================
ЧТО ЭТО
========================================
VK-бот для удалённого управления ПК.
Умеет: камера, скриншоты, скачивание видео,
выключение, перезагрузка, блокировка.

========================================
УСТАНОВКА
========================================

1. Установи Python 3.14
   - Скачай с python.org
   - При установке поставь галочку "Add python.exe to PATH"

2. Установи библиотеки
   Открой CMD и выполни:
   py -3.14 -m pip install vk_api opencv-python pillow requests yt-dlp

3. Установи ffmpeg
   - Скачай с gyan.dev/ffmpeg/builds/
   - Распакуй в C:\ffmpeg
   - Добавь C:\ffmpeg\bin в PATH
   Или скопируй ffmpeg.exe и ffprobe.exe в папку с ботом.

4. Настрой IP Webcam на телефоне
   - Установи IP Webcam из Google Play
   - Запусти сервер
   - Запиши IP (например, 192.168.0.180:8080)
   - Вставь IP в vk_bot.pyw:
     CAMERA_URL = "http://192.168.0.180:8080/video"

5. Запусти бота
   py -3.14 vk_bot.pyw
   Или через start.bat (запуск в фоне)
